React Hooks & Render Visualizer

Understand state updates, silent refs, and memoization under the hood

🎮 Visualizer Experiments to Try:

1
Click "Increment State". Both the parent and the Non-Optimized Child render counts will increase. Why? Because state changes trigger parent renders, which automatically trigger child renders.
2
Click "Increment Ref Silently". The Ref value increases in the background (check console or card), but the UI count does NOT update and the render count stays at 0. Refs do not trigger updates!
3
Observe the Optimized Child. Why is its render count lower? Because it is wrapped in React.memo() and receives a memoized function using useCallback. React skips re-rendering it because its props didn't change!
