Module 1 CORS Playground

Understand browser origin protection visually. Hosted on: localhost:3000

API call WITHOUT CORS Will Block

Calls GET http://localhost:5050/api/no-cors. The backend server returns JSON, but doesn't send Access-Control-Allow-Origin. Your browser blocks the JavaScript client from accessing the response.

Status: -
Click the button to send the request...

API call WITH CORS Will Pass

Calls GET http://localhost:5050/api/with-cors. The backend server returns JSON and sends Access-Control-Allow-Origin: http://localhost:3000. The browser validates it and lets the JS client read it.

Click the button to send the request...

🔍 Under the Hood

Open your browser's Developer Tools (Press F12 or Ctrl+Shift+I, and go to the Console tab). When you execute the "Without CORS" request, you will see a system error raised directly by your browser blocking the script:

Access to fetch at 'http://localhost:5050/api/no-cors' from origin 'http://localhost:3000' has been blocked by CORS policy: No 'Access-Control-Allow-Origin' header is present on the requested resource.
